One key idea per image

The skill doesn't decorate your article — it finds a cognitive anchor and makes Xiaohei, a deadpan little worker, physically perform it. Below: the skill's method applied to its own translation story.

Install

Claude Code — as a plugin (recommended)

/plugin marketplace add venikman/ian-xiaohei-illustrations
/plugin install ian-xiaohei-illustrations@xiaohei

Claude Code — as a plain skill

git clone https://github.com/venikman/ian-xiaohei-illustrations.git
mkdir -p ~/.claude/skills
cp -R ian-xiaohei-illustrations/skills/ian-xiaohei-illustrations ~/.claude/skills/

Codex

git clone https://github.com/venikman/ian-xiaohei-illustrations.git
cd ian-xiaohei-illustrations
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R ./skills/ian-xiaohei-illustrations "${CODEX_HOME:-$HOME/.codex}/skills/"

Then just ask for Xiaohei illustrations (Claude Code) or Use $ian-xiaohei-illustrations … (Codex). Generating final images needs an image-generation tool — built into Codex; in Claude Code, connect any image-generation MCP.

Xiaohei is not a mascot — Xiaohei is an absurd worker earnestly keeping the system running.
